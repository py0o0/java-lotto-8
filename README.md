# java-lotto-precourse

## 기능 요구사항
- 사용자는 구매 금액을 입력한다.
  - 구매 금액은 1000의 배수의 정수여야 한다.

- 사용자는 당첨 번호를 입력한다.
  - 당첨 번호는 1~45 사이의 정수 6개여야 한다.
  - 당첨 번호는 중복되지 않는다.

- 사용자는 보너스 번호를 입력한다.
  - 보너스 번호는 1~45 사이의 정수여야 한다.
  - 보너스 번호는 중복되지 않는다.

- 랜덤으로 로또를 뽑는다.
  - 로또는 정렬되있어야 한다.

- 당첨 통계를 발표한다.

- 수익률을 발표한다.
  - 수익률은 소수점 둘째 자리에서 반올림한다.

- 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.
